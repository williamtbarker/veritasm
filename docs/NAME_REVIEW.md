# Project naming

VeritAsm remains a working project name. The 2026-09-03 naming review did not
establish trademark clearance or reserve a package name.

The review recorded these observations:

- The crates.io lookup returned no exact `veritasm` package at that time.
- The [GitHub account `veritasm`](https://github.com/veritasm) was already occupied.
  Account names and repository names under another account are separate namespaces.
- The letter sequence also appeared in unrelated publishing and software contexts,
  including [VeritasM publishing records](https://www.yes24.com/product/goods/3486712)
  and the similarly named [VERITAS ECG software](https://www.hillrom.ca/en/products/diagnostic-cardiology-suite/).
- No exact assembler product was found by that limited review, but some registry
  and repository searches were incomplete.

These are dated search observations. Revisit naming before a formal product or
crate release; the development checkpoint does not establish ownership of the name.
